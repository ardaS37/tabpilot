# TabPilot

**Work in progress.** An Android tablet controller with an AMOLED-friendly interface and S Pen-aware interaction options. It sends keyboard and mouse commands to a Windows PC over an ADB reverse tunnel.

## Components

- `android-controller` — Android touch, stylus, mapping, and control-surface UI
- `windows-receiver` — .NET receiver for keyboard and mouse commands

## Current features

- Customizable directional and action mappings
- Touchpad-style mouse control
- S Pen and stylus interaction experiments
- Local profiles saved per device
- Safe release of held keys when the app disconnects

## Status

**Work in progress.** The first controller path is functional; gamepad support, broader Samsung device testing, and polish are planned.
